maps.jochenklar.de
==================

Compare tiled maps side by side at [maps.jochenklar.de](https://maps.jochenklar.de).
The app is [@jochenklar/maps](https://github.com/jochenklar/maps), this repository only
contains the config.


Setup
-----

Install the dependencies:

```bash
nvm use
npm install
```


Usage
-----

```bash
npm run dev      # start the development server
npm run build    # build the static site into dist/
npm run preview  # serve the build locally
```
